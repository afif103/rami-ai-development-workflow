# Rami Afif AI Development Workflow

**Version 2.6 — Consolidated Full Edition**

A human-governed AI-assisted software-development workflow with architect–implementer challenge, iterative re-challenge, evidence-based review, and controlled human approval gates.

## About and Authorship

Designed and documented by Rami Afif.

The Rami Afif AI Development Workflow v2.6 is a human-governed AI-assisted software-development process developed through practical work on production-style AI and SaaS projects.

It combines architect–implementer technical challenge, iterative revised-plan re-challenge, independent diff review, requirement-to-test traceability, controlled implementation visibility, separate human approval gates, and a post-packet workflow-learning loop.

Individual practices such as testing, code review, human approval, and agent orchestration existed previously. This repository documents Rami Afif’s specific consolidated workflow, structure, terminology, governance rules, and practical implementation.

## Key Components

* Architect–Implementer Challenge Protocol
* Iterative Revised-Plan Re-Challenge Loop
* Post-Implementation Reviewer–Implementer Challenge Gate
* Implementation Visibility and Transparency Rule
* Requirement-to-Test Traceability
* Independent Diff Review
* Separate Human Approval Gates
* Controlled Workflow Learning Loop
