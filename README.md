# Rami Afif AI Development Workflow

**Version 2.6 — Consolidated Full Edition**

A human-governed AI-assisted software-development workflow with architect–implementer challenge, iterative re-challenge, evidence-based review, and controlled human approval gates.

## About and Authorship

The Rami Afif AI Development Workflow v2.6 was designed, consolidated, tested through practical project work, reviewed, and documented under the direction of Rami Afif, with AI-assisted drafting and editing.

The workflow is a human-governed AI-assisted software-development process developed through practical work on production-style AI and SaaS projects.

It combines:

* architect–implementer technical challenge;
* iterative revised-plan re-challenge;
* post-implementation reviewer–implementer challenge;
* independent diff review;
* requirement-to-test traceability;
* controlled implementation visibility;
* separate human approval gates; and
* a post-packet workflow-learning loop.
